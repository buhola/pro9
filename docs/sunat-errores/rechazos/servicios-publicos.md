# Servicios públicos

:::danger[Rechazo]
SUNAT **rechaza** el comprobante. Hay que corregir el XML o los datos y volver a emitirlo (con otra numeración si el número ya quedó informado).
:::

Recibos de servicios públicos (luz, agua, telecomunicaciones): suministro, medidor, tarifa y notas asociadas.

**Rango:** `2900` – `2999` · **100** códigos.
