# Cambio de moneda, GRE y percepción

:::danger[Rechazo]
SUNAT **rechaza** el comprobante. Hay que corregir el XML o los datos y volver a emitirlo (con otra numeración si el número ya quedó informado).
:::

Tipo de cambio, guías relacionadas, destinatario/tercero y montos de percepción.

**Rango:** `2700` – `2799` · **100** códigos.
