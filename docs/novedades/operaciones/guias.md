# 🚚 Guías de remisión

- **Botón para reemplazar el nombre del producto** directamente en la tabla, mediante un modal.
- La guía se **regenera siempre con la plantilla vigente**.
- **Transportistas** que se pueden crear solo con RUC.
- **Búsqueda de licencia de conducir** junto con el DNI en los formularios.
- Al generar un comprobante desde una guía, se selecciona la caja de destino por defecto.
- Ya no se exige ubigeo obligatorio al crear un cliente desde una guía.
- Se corrigió el campo de cantidad en el modal.
- Ajuste en la verificación del modo de transporte y en la respuesta del envío.
