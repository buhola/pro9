# 📱 Vendeya y Mozo

### Vendeya (venta móvil)
- Panel de configuración propio y mejoras generales de interfaz.
- **Búsqueda sobre todos los clientes activos**, y corrección del orden alfabético.
- Consultas de stock y de productos **optimizadas** (respuesta más rápida).
- Columna de **origen** en boletas y notas de venta, para identificar de dónde vino cada venta.

### Mozo (atención en mesa)
- **Accesos de mozo**: se genera un enlace para compartir con el personal, que no necesita iniciar sesión, y se copia automáticamente.
- El acceso vive en el menú principal, ya no escondido en configuraciones.
- **Editor de logo** y configuración global de marca y colores.
- Instalable como aplicación (PWA) con su propia ruta.
- No permite agregar productos sin stock.
- Los datos y el rol del usuario se cargan correctamente al ingresar.

- **Módulo Vendeya**: ahora los administradores pueden permitir que cada usuario use Vendeya, mejorando la gestión de inventarios y ventas.
- **Módulo Mozo y Impresión**: se corrigió un problema para enviar la dirección IP del cliente al registrar órdenes de impresión, mejorando la trazabilidad de las mismas.
- **Módulo Vendeya**: ahora puedes acceder a la aplicación Vendeya mediante un acceso directo sin complicaciones, mejorando tu experiencia al iniciar sesión.
- **Módulo Vendeya**: se han corregido las migraciones para asegurar que el módulo de Vendeya funcione correctamente, mejorando así la estabilidad del sistema.
- **Módulo Vendeya**: la ventana instalada ahora utiliza la ruta adecuada para una mejor integración con Vendeya, mejorando la experiencia del usuario.
