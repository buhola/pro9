# 📱 Vendeya y Mozo

### Vendeya (venta móvil)
- Panel de configuración propio y mejoras generales de interfaz.
- **Búsqueda sobre todos los clientes activos**, y corrección del orden alfabético.
- Consultas de stock y de productos **optimizadas** (respuesta más rápida).
- Columna de **origen** en boletas y notas de venta, para identificar de dónde vino cada venta.

### Mozo (atención en mesa)
- **Accesos de mozo**: se genera un enlace para compartir con el personal, que no necesita iniciar sesión, y se copia automáticamente.
- El acceso vive en el menú principal, ya no escondido en configuraciones.
- **Editor de logo** y configuración global de marca y colores.
- Instalable como aplicación (PWA) con su propia ruta.
- No permite agregar productos sin stock.
- Los datos y el rol del usuario se cargan correctamente al ingresar.
