# 🖥️ POS y Venta Rápida

- **Navegación por teclado (focus ring)** en formularios, modales, inputs y pagos: se ve siempre dónde estás parado.
- **División de pagos** en Venta Rápida.
- **Términos y condiciones** visibles en los comprobantes generados desde POS y Venta Rápida.
- Aviso cuando se factura a un cliente **sin RUC**.
- Validación para **no vender por debajo del precio de compra**.
- El POS usa **nota de venta por defecto**.
- Se respeta si el vendedor **tiene o no permitido aplicar descuentos**.
- Alerta cada vez que se elige una búsqueda de precio.
- **Panel de configuración de categorías** en el POS.
- Se corrigió el tamaño del ticket en la vista previa.
- Botón *Agregar* corregido en la pantalla de pagos.
