:::

# 🏬 Marketplace *(módulo nuevo)*

- Nuevo módulo que trabaja en conjunto con tus clientes y productos.
- **Carrito de compras** propio.
- **Recomendaciones** con límite por visitante y **ranking natural** según cuántos usuarios recomiendan cada producto.
- **Captcha y solicitud de datos** antes de entregar la URL de compra.
- **Token secreto por tienda** para evitar clonaciones.
- **Exportación del histórico de compras** con datos de seguridad.
- **Interruptor maestro** para activar o desactivar el marketplace completo.
- Mejoras generales de interfaz y textos.
