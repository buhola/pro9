# 🔌 API y App Móvil

- Consulta **por ID** de comprobantes, notas de venta, cotizaciones, compras y guías de remisión.
- Nuevos recursos de **cuentas bancarias** y **planes**.
- **Unidades de medida** del negocio expuestas a la app móvil.
- Datos de compra del producto disponibles en el listado.
- El **logo del establecimiento** tiene prioridad sobre el logo general.
- Endpoint de **estadísticas** para la app.
- Listas de precios de productos expuestas para venta móvil.
- Endpoints renombrados para evitar conflictos con la app móvil.
