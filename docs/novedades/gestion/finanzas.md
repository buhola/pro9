# 💰 Finanzas

- **Impresión de pagos** en cuentas por cobrar.
- El botón de exportar solo actúa cuando hay comprobantes con saldo pendiente.
- Validación de extensiones de archivo, con mensaje claro cuando no se permite.
- **Notas de venta**: traen la condición de pago al editar y regeneran las cuotas según el estado actual.
- El ticket personalizable de nota de venta muestra condición y método de pago.
- **Métodos de pago**: campo de estado activable con un interruptor, conectado a la lógica de comprobantes.
