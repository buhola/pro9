# 🛍️ Compras y Órdenes de compra

- Desde una orden de compra ahora se **genera una compra nueva** en lugar de actualizarla.
- Se respetan los **días de crédito de cada proveedor**.
- Se permiten valores numéricos con **más de dos decimales**.
