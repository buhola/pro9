# 🛍️ Compras y Órdenes de compra

- Desde una orden de compra ahora se **genera una compra nueva** en lugar de actualizarla.
- Se respetan los **días de crédito de cada proveedor**.
- Se permiten valores numéricos con **más de dos decimales**.

- **Nrus**: Convertir NRUS de giro de negocio a régimen con switch propio
- Editar ApidocsService.php
- **Gestión de Compras**: Se solucionó un problema en las Órdenes de Compra para que las opciones de pago a crédito se muestren correctamente de nuevo, permitiéndole elegir las condiciones que necesita con sus proveedores.
- **Gestión de Compras**: Hemos añadido la capacidad de gestionar productos con variaciones (por ejemplo, diferentes colores, tallas) en todas sus compras, órdenes de compra y cotizaciones de compra. Además, ahora la fecha de vencimiento de las Órdenes de Compra se establecerá automáticamente según la forma de pago elegida, simplificando la administración de sus compromisos.
