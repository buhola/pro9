# 🧩 Otros módulos

- **Recepción**: las horas de entrada y salida se eligen con un selector de hora o se escriben manualmente; se puede crear un cliente nuevo escribiendo solo el número.
- **Farmacia**: exportación de etiquetas corregida, con consistencia entre el código de barras y los números.
- **Pedidos**: nuevos estados para envíos, flujo de estados mejorado, selección por defecto del descuento que afecta y desbloqueo de la edición de descuentos.
- **Cotizaciones**: el descuento del producto se guarda y se aplica sobre el precio original, no sobre el precio ya descontado.
- **Soporte técnico**: alineación de columnas en el listado y en el panel de detalle.
- **Preventa**: se puede generar una cotización o un pedido aunque el dólar esté desactivado.
