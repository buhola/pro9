Catálogo de errores SUNAT

Cuando Pro 9 envía un comprobante, SUNAT (o el OSE) responde con un código numérico. Ese código dice si el envío falló, si el XML se rechazó o si el documento se aceptó con observaciones.

El menú de la izquierda es solo de errores SUNAT. Las novedades de Pro 9 están en su propio menú.

SUNAT

Catálogo de códigos de la facturación electrónica de SUNAT. Aplica al envío directo a SUNAT y al envío a través de un OSE.

Error de servicio0100–0499

No se procesó el envío. Hay que reenviar.

Rechazo1000–3999

El comprobante no se acepta. Hay que corregir y volver a emitir.

Observación4000–4338

El comprobante sí se acepta, con un aviso para corregir.

Por tipo​

  • Errores de servicio — autenticación, ZIP y lote
  • Rechazos — estructura XML y reglas de negocio
  • Observaciones — aceptado con aviso

Códigos que suelen verse primero​

CódigoQué suele significar
0100SUNAT no pudo responder. Reintentar.
0102 / 0103 / 0104Usuario o clave SOL incorrectos.
0111 / 0113El usuario no está afiliado o no tiene perfil de factura electrónica.
0154El RUC del XML no coincide con el usuario que envía.
0402Esa serie-número ya fue enviada.
1032 / 1033El comprobante ya estaba informado (anulado/rechazado o con otros datos).
2010 / 2011El contribuyente no está activo o no está habido.
2325–2328Problema con el certificado digital (baja, vencido o revocado).
2329Fecha de emisión fuera del plazo permitido.
2396Monto mayor a S/ 700 sin documento de identidad del cliente.
4000+Aceptado con observación: revisa el detalle, no es un rechazo.

Usa la búsqueda del sitio (o Ctrl + K) para localizar un código concreto.
